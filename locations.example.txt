# Правила для мест. Скопируй файл в locations.txt и впиши свои места:
#   cp locations.example.txt locations.txt
# Правила применяются при каждом «Обновить из каталога».
#
#   Главное <- Вариант 1, Вариант 2     объединить: варианты станут синонимами главного
#   Составное = Место 1 + Место 2        одно название папки → несколько мест (без «+» в названии)
#   не место: Название, Название         тесты, люди, общие слова — не идут в прогноз
#   поездка: Название, Название          за пределами региона — отдельно от прогноза
#
# Регистр и ё/е не важны. Названия через «+» в папках разбиваются сами.

# --- Объединение ---
Северный мыс <- Северный, Мыс Северный
Тихое озеро <- Тихое, Оз. Тихое
Сосновый бор <- Бор

# --- Составные названия без «+» ---
Мыс Бухта = Северный мыс + Песчаная бухта

# --- Типы ---
не место: Тест объектива, Дом, Город
поездка: Горы 2025, Степь
